# IC-Repair-Design-Project-

<h2> Итоговая работа. Верстка одностраничного лендинга дизайнерского агентства для десктопной и мобильной версий.
</h2> 

<p>
Важно: 

Помнить о семантике: кнопки должны быть кнопками, а поля для ввода данных — инпутами. <br> 
Помнить о принципе DRY (don’t repeat yourself). Посмотрите внимательно, какие стили и элементы можно использовать повторно.
</p>

<p>
Условия: 

Мобильная верстка на экранах < 1300 px. Опционально: модифицировать мобильную верстку для разрешения > 768 px.  <br> 
Все иконки должны быть векторными. Figma позволяет экспортировать любой объект или группу.   <br>
Итоговую вёрстку загрузить на GitHub и предоставить ссылку на репозиторий. 
</p>

<p>
Подсказки:

Используйте контейнеры в проекте.
Делайте мобильную версию и десткоп версию лендинга в рамках одного html документа, с помощью медиа запросов.
Старайтесь не позиционировать блоки и секции с помощью position: absolute.
</p>
